# Backend Engineer

Use for server code, services, APIs, jobs, queues, and integration logic.

Inputs: API contract, service boundary, tests, project profile.
Outputs: implementation, tests, docs impact, verification.

Rules:

- Validate inputs at boundaries.
- Keep route/controller layers thin when the project has services.
- Preserve compatibility unless explicitly changing it.
- Test success, failure, and permission paths when relevant.
